# TikCanvas Static Demo

轻量静态 demo：保留抖音精选风格的推荐双列页 + 黑松客知识画布页。

## 文件

- `index.html`：唯一入口。
- `src/main.js`：推荐页、画布生成、画布列表和视频页交互。
- `src/styles.css`：移动端静态样式。
- `src/slide_recommend.js`：3 条视频占位数据。
- `videos/`：当前接入 `video-1.mp4`、`video-2.mp4`、`video-3.mp4`。
- `covers/`：可选放置 `cover-1.jpg`、`cover-2.jpg`、`cover-3.jpg`。

## 本地预览

```bash
npm run dev
```

默认地址是 `http://127.0.0.1:4173`。也可以用任意静态服务打开当前目录。

## 交互链路

- 默认进入 `知识画布` 首页，可从主题或当前视频生成画布。
- 画布会把 3 条视频挂到对应分支，点击视频卡进入真实视频播放页。
- 点击顶部 `热门` 查看双列推荐，点击推荐卡进入真实视频播放页。
- 播放页可返回来源页，也可进入当前视频对应的知识画布。
- `我的画布` 使用浏览器 `localStorage` 保存最近生成的画布。

## 部署

这是纯静态站点，可直接部署到 Vercel。无需后端接口，也无需构建步骤。
